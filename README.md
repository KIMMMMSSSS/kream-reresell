# kream-reresell

KREAM 랭킹에서 상품을 자동 순회하면서 각 사이즈의 가격을 비교하고, 조건을 만족할 때 최우선 구매입찰을 만들거나 기존 입찰가를 갱신하는 자동화 프로젝트입니다.

## 확정된 작업 흐름

1. KREAM 로그인
2. 사용자가 랭킹에서 원하는 카테고리 선택
3. 해당 랭킹 상위 100개 상품 자동 순회
4. 상품마다 화면에 나뉘어 있는 모든 사이즈 칸을 순회
   - 숫자 사이즈뿐 아니라 S/M/L/XL 등도 그대로 처리
5. 사이즈별 가격 확인
   - 정상 일반배송 가격
   - 정상 빠른배송 가격
   - 95점 상품 제외
   - 해외배송 제외
   - 일반배송 또는 빠른배송 중 한 종류라도 없으면 해당 사이즈 스킵
6. 기준가격 = 정상 일반배송 / 정상 빠른배송 중 낮은 가격
7. 차액 = 기준가격 - 즉시판매가
8. 아래 최소 차액을 만족하는지 판정
9. 조건을 만족하면 구매입찰 처리
10. 기간 30일, 창고보관
11. 다음 사이즈 / 다음 상품으로 반복

## 가격 기준

- 50,000 ~ 99,999원: 최소 차액 10,000원
- 100,000 ~ 149,999원: 최소 차액 13,000원
- 150,000 ~ 249,999원: 최소 차액 18,000원
- 250,000 ~ 349,999원: 최소 차액 23,000원
- 350,000 ~ 450,000원: 최소 차액 28,000원

## 최우선 구매입찰 로직

KREAM의 즉시판매가는 현재 가장 높은 구매입찰 가격으로 사용한다.

- 내 기존 입찰이 없음:
  - 목표 입찰가 = 즉시판매가 + 1,000원
  - 신규 구매입찰

- 내 기존 입찰이 있고, 이미 최우선 입찰:
  - 가격 유지
  - 자기 입찰을 보고 또 +1,000원 올리는 동작 금지

- 내 기존 입찰이 다른 입찰에 밀림:
  - 목표 입찰가 = 현재 즉시판매가 + 1,000원
  - 기존 입찰 가격 변경

- 현재 신규 조건을 만족하지 않는데 기존 입찰이 이미 있는 경우:
  - 현재는 자동 취소하지 않고 유지
  - 자동 취소 여부는 별도 규칙이 정해지면 추가

## 현재 구현 상태

완료:
- 상품 ID 직접 입력 방식 제거
- 랭킹 상품 URL 자동 수집
- 기본 상위 100개 순회
- 카테고리별로 화면에 보이는 모든 사이즈 칸 읽기
- 구간별 차액 판정
- 일반배송/빠른배송 둘 다 있을 때만 판정
- 신규 / 유지 / 가격변경 의사결정 로직
- 가격 로직 자동 테스트

진행 중:
- 실제 KREAM 화면에서 일반배송/빠른배송/95점/해외배송/즉시판매가 추출
- 내 기존 입찰 여부와 기존 입찰가 읽기
- 기존 입찰 가격 변경 화면 자동화
- 최종 입찰 제출 자동화

인증, CAPTCHA, 추가 본인확인이 나타나면 자동 우회하지 않고 중단합니다.
