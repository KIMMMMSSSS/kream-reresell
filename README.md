# kream-reresell

KREAM 구매입찰 보조 자동화 프로젝트.

## 목표

사람이 실행한 뒤 상품을 확인하고, 조건에 맞는 사이즈를 찾아 구매입찰 준비까지 자동화합니다.

초기 버전은 **DRY RUN이 기본값**입니다. 실제 최종 입찰 제출은 자동으로 하지 않습니다.

## 현재 기준

- 기준가격 = 정상 일반배송 / 정상 빠른배송 중 낮은 가격
- 95점 상품 및 해외배송 제외
- 차액 = 기준가격 - 즉시판매가
- 구간별 최소 차액:
  - 50,000 ~ 99,999원: 10,000원
  - 100,000 ~ 149,999원: 13,000원
  - 150,000 ~ 249,999원: 18,000원
  - 250,000 ~ 349,999원: 23,000원
  - 350,000 ~ 450,000원: 28,000원
- 입찰 희망가 = 즉시판매가 + 1,000원
- 입찰 기간 = 30일
- 보관 방식 = 창고보관

## 개발 단계

1. 가격 판정 엔진
2. 실제 KREAM 상품 페이지의 가격/사이즈 수집
3. 구매입찰 화면 자동 입력
4. 검증 후 선택적으로 최종 제출 자동화

인증, CAPTCHA, 추가 본인확인 등이 나타나면 자동 우회하지 않고 중단합니다.
