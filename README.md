# kream-reresell

KREAM 랭킹을 사람이 선택한 뒤, 프로그램이 상품을 위에서부터 하나씩 순회하며 조건에 맞는 사이즈를 찾는 자동화 프로젝트입니다.

## 최종 목표

1. 프로그램 실행
2. KREAM 로그인
3. 랭킹 화면에서 원하는 카테고리를 사람이 직접 선택
4. 프로그램이 랭킹 상품을 위에서부터 자동 순회
5. 상품마다 240~320 사이의 실제 존재하는 사이즈 확인
6. 각 사이즈의 정상 일반배송 / 정상 빠른배송 가격 확인
   - 95점 상품 제외
   - 해외배송 제외
7. 즉시판매가 확인
8. 가격 기준으로 자동 판정
9. 조건 통과 시 즉시판매가 + 1,000원으로 구매입찰 준비
10. 입찰 기간 30일
11. 창고보관 선택
12. 다음 사이즈 / 다음 상품으로 반복

## 가격 기준

- 기준가격 = 정상 일반배송 / 정상 빠른배송 중 낮은 가격
- 차액 = 기준가격 - 즉시판매가
- 50,000 ~ 99,999원: 10,000원
- 100,000 ~ 149,999원: 13,000원
- 150,000 ~ 249,999원: 18,000원
- 250,000 ~ 349,999원: 23,000원
- 350,000 ~ 450,000원: 28,000원

## 현재 구현 상태

현재 버전은 안전한 1차 DRY RUN입니다.

- 상품 ID 직접 입력 방식 제거
- KREAM 랭킹 자동 진입
- 카테고리는 사람이 직접 선택
- 현재 랭킹 화면에서 상품 URL 자동 수집
- 상품을 하나씩 자동 방문
- 각 상품에서 240~320 사이즈 목록 읽기
- 실제 거래 제출은 하지 않음

다음 단계는 각 사이즈에서 일반배송 / 빠른배송 / 95점 / 해외배송 / 즉시판매가를 정확히 읽는 로직입니다.

인증, CAPTCHA, 추가 본인확인이 나타나면 자동 우회하지 않고 중단합니다.
